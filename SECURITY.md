# Security reports

Report vulnerabilities through GitHub's private vulnerability reporting for
this repository: https://github.com/noeljackson/atmos-openbao-auth/security/advisories/new

Include the plugin/Atmos versions, affected platform, relevant configuration
with credentials removed, and a synthetic reproduction where possible. Never
include tokens, private keys, session files or live request captures in a public
issue. If private reporting is unavailable, contact the maintainer through
their GitHub profile before disclosing details publicly.

The initial 0.x release is experimental. Its supported behavior and tested
platforms are documented in README.md; synthetic tests do not establish
acceptance of a particular live issuer or session service.
